The FROST Python Client (`frost_sta_client`) is an open-source Python library that simplifies working with [OGC SensorThings API](https://github.com/opengeospatial/sensorthings) servers — including the [FROST-Server](https://github.com/FraunhoferIOSB/FROST-Server) from Fraunhofer IOSB. It handles HTTP communication, JSON serialization, query building, and automatic pagination so you can focus on your sensor data instead of API plumbing.

## Get started in 60 seconds

<Steps>
  <Step title="Install the package">
    ```bash
    pip install frost_sta_client
    ```
  </Step>
  <Step title="Connect to a FROST server">
    ```python
    import frost_sta_client as fsc

    service = fsc.SensorThingsService("http://localhost:8080/FROST-Server/v1.1")
    ```
  </Step>
  <Step title="Query your first entities">
    ```python
    things = service.things().query().list()
    for thing in things:
        print(thing.name)
    ```
  </Step>
  <Step title="Create an entity">
    ```python
    thing = fsc.Thing(name="My Sensor Node", description="A temperature sensor on the roof")
    service.create(thing)
    print(f"Created Thing with id: {thing.id}")
    ```
  </Step>
</Steps>

<Note>
  Need a local FROST server for development? The repository includes a Docker Compose file at `frost_server/docker-compose.yaml` that spins up a fully configured FROST-Server with PostgreSQL in seconds.
</Note>
